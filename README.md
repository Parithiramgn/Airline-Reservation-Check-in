## Problem Statement
To develop a Java console application for airline reservations, bookings, payments, and passenger check-in.
Specification 18: Airline Reservation &amp; Check-in
Problem Statement: Design and implement a Java console application for an Airline Reservation &amp;
Check-in system that handles flights, seats, bookings, payments, and boarding passes. The
application should demonstrate object-oriented principles and prevent double booking.

Department of Computer Science and Engineering


Class Requirements: Flight, Aircraft, Seat, Passenger, Booking, Payment, BoardingPass
Business Rules:
1. Seats can be booked only if available for the selected flight.
2. Payment confirmation is required before issuing a boarding pass.
3. Cancellations should release seats immediately as per policy.
4. Check-in assigns seats and generates boarding passes.
5. Each booking should link directly to a flight, passenger, and seat(s).
Menu Options: Add Flight / Add Passenger / Create Booking / Make Payment / Check-in &amp; Issue
Boarding Pass / Cancel Booking / Display Flights / Exit
Expected Output:
• Show booking receipt with flight, seats, fare, taxes, total amount.
• Show boarding pass with passenger, flight, seat, and gate/timestamp.
• Show updated seat availability after booking, check-in, or cancellation.

## How to Run
1. Open the project in Eclipse IDE.
2. Open `Main.java`.
3. Right-click and select **Run As → Java Application**.

This project demonstrates object-oriented programming, exception handling, input validation, and basic airline reservation management using Java.
